Rangkuman Komputasi Awan

Komputasi awan adalah layanan komputasi berbasis internet yang memungkinkan pengguna mengakses sumber daya tanpa harus memiliki infrastruktur sendiri.

Karakteristik

  • Resource Pooling
  • Broad Network Access
  • Measured Service
  • Rapid Elasticity
  • Self Service

Model Layanan

  • SaaS
  • PaaS
  • IaaS

Deployment Model

  • Public Cloud
  • Private Cloud
  • Hybrid Cloud
  • Community Cloud

Kesimpulan

Cloud computing memberikan fleksibilitas dan efisiensi dalam penggunaan teknologi.
